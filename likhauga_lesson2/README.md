# LikhaUgat — Lesson 2

Interactive presentation website for **Filipino Identity through the Arts**.

## Open

Open `index.html` in a modern browser. Select **Present Fullscreen** for classroom use.

## Controls

- Previous/next buttons
- Left and right arrow keys
- Space for next slide
- `F` for fullscreen
- Left-side table of contents

## Blackboard activity files

Each named activity has a red **Save PNG** button. Student responses are rendered into a branded image and downloaded by the browser.

The assessment also requires the student’s name and downloads a result PNG showing the name and score.

## Visual galleries

- Click any textile, object, or instrument card to open its description inside the presentation.
- Every photograph throughout the presentation can be replaced with the teacher’s own image file.
- Photo controls are hidden by default. Select **Show photo tools** in the left sidebar, replace the needed images, then select **Hide photo tools** before presenting.
- Replacement photos are resized automatically and retained in the same browser when storage space allows.
- The performance library contains Music, Dance, and Theater/Epic tabs with 12 suggested videos.

## Revised activity displays

- Activity 2 shows one selected artwork at a large study size. The five artwork names switch the main image; students do not need to interpret tiny thumbnails.
- Activity 3 uses only three clearly separated choices: A—Hudhud Chants, B—Kulintang Ensemble, or C—Pangalay. The selected performance name appears in the downloaded PNG.

## GitHub Pages

Upload the contents of this folder to a GitHub repository. In **Settings → Pages**, deploy from the main branch and root folder. Use the published URL as the `src` of your Blackboard iframe.

## Internet use

The main lesson and PNG exports work without external libraries. Gallery photographs and YouTube examples require an internet connection. Preview video links before class.
